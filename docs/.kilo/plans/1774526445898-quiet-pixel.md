# AI Architecture Simplification Plan

- ✅ Wiped custom AI infrastructure dependencies from the `package.json` files.
- ✅ Removed Electron main process AI layers (`LocalAiRuntimeService`, `ProviderAuthService`, `LocalMcpToolRuntime`).

## 3. Deployment
- 🚀 Run `npx convex deploy` to finalize the schema demolition and synchronize the simplified Convex backend to production.

## 4. PTY Rust Migration (Future Phase)
- 💡 **Evaluation:** As verified, replacing `node-pty` with a Rust-based PTY backend using `@napi-rs/cli` and `portable-pty` is highly recommended. It will act as a 1-to-1 drop-in replacement for the `TerminalService` to eliminate Node ABI compilation issues, crashes, and resource leaks.
- ⏳ **Execution:** Since the terminal UI changes have stabilized, the Rust migration can be executed in the next turn seamlessly without altering any frontend code.
