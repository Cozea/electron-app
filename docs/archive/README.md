# Archive

Plans, audits, checklists and inventories whose work has landed, been superseded, or
describes a codebase layout that no longer exists. They are kept for the history and the
recovery patterns they record, not as implementation guidance.

Do not follow a document here without checking it against the current code and the
living documents one level up. If something here is still true and still needed, move it
back out rather than linking into the archive from new work.
