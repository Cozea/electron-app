## Considered and rejected (do not re-audit these)

- **"server/.env committed with live secrets" — FALSE.** `server/.env` and `.env.local` exist on disk but are gitignored and have **never** been committed (`git ls-files` shows only `.env.example`; `git log --all -- server/.env .env.local` is empty). No rotation needed on this evidence.
- **Shell injection via branch names / `gh repo create` args — rejected.** All git/gh invocations in `electron/ipc/registerProjectHandlers.ts` use `spawn` with argument arrays (no shell): `runGitCommand(['checkout', branch], cwd)`, `runGhCommand(['repo','create',...])` (:933-945, :1081-1084).
- **`env: { ...process.env }` passed to the `gh` child process — rejected.** Equivalent to default child-process env inheritance; `gh` needs its auth environment.
- **`JSON.stringify` comparison in `useProjectWorkspaceResolution.ts:88-94` as a perf bug — rejected.** It is the deliberate, commented SWR identity-preservation mechanism, runs once per IPC resolution (not per render) on a small object.
- **"30+ test files never run in CI because secondary vitest configs aren't invoked" — rejected.** `vitest.config.ts` includes `tests/**/*.test.ts`, which covers those files in the default `bun run test` CI step. (Alias-divergence residue kept in backlog above.)
- **DevTools enabled in non-release builds (`electron/main.ts:1277`) — by design** (dev UX).
- **Browser-tile WebContentsView config — acceptable.** `sandbox: true, contextIsolation: true` verified (`electron/services/WorkbenchBrowserService.ts:501-509`).
- **Icon-library consolidation (4 libraries) — not worth doing.** `@hugeicons` dominates (158 imports); swap churn outweighs the bundle win.
- **AGENTS.md "How Project Creation Works" drift — minor.** Code comment in `convex/projects.ts` documents the saga statuses (`draft`/`provisioning`/`active`); AGENTS.md's two-step description is close enough that a rewrite wasn't worth a plan. Revisit if the catalog branch changes the flow again.
- **effect-smol pins, ACP v0.11.3 pin, 46 `@ts-nocheck` files, tests-not-typechecked, vitest-under-Node — documented, deliberate tradeoffs** (AGENTS.md), not findings.
